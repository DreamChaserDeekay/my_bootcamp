🔓 Vulnerable App — 학습용

⚠ 이 앱은 의도적으로 취약합니다. 로컬에서만 사용하세요.

실습 메뉴

❌ /vuln/* — 취약

  • SQL Injection — 로그인
  • SQL Injection — 검색
  • OS Command Injection
  • Stored XSS — 게시판
  • IDOR — 주문 조회
  • SSRF — Fetch
  • File Upload

✅ /safe/* — 패치 후

  • SQLi 차단
  • SQLi 차단
  • CmdInjection 차단
  • XSS 차단
  • IDOR 차단
  • SSRF 차단
  • Upload 안전

실습 가이드

  1. 각 vuln 엔드포인트에 공격 시도 → 성공 확인
  2. 같은 공격을 safe 엔드포인트에 시도 → 차단 확인
  3. 차이점을 코드(src/main/java)에서 한 줄씩 비교
