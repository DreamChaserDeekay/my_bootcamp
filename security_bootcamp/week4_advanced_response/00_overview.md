# Week 4 — 시스템/바이너리·DevSecOps·사고 대응·캡스톤

## 한 줄 요약
공격·방어를 **운영 사이클**에 통합하고, **사고가 났을 때** 무엇을 어떻게 하는지 익힌다. 시스템·바이너리는 부수적으로 다루되 RCE 사고 분석에 필요한 기초만.

## 학습 목표
- [ ] 메모리·바이너리 취약점(버퍼 오버플로우, ROP)의 기본 원리 이해
- [ ] 리버싱·악성코드 분석의 기초 (Ghidra/IDA 입문)
- [ ] CI/CD 파이프라인에 SAST/DAST/SCA 통합
- [ ] Secure SDLC 설계
- [ ] 위협 모델링 v2 (실전 적용)
- [ ] 사고 대응 플레이북·러닝 익히기 (탐지·억제·복구·교훈)
- [ ] **캡스톤**: 본인 시스템 보안 평가 보고서
