# 사용자 가이드 (글로벌)

> 이 파일은 Claude Code가 모든 프로젝트·세션에서 자동으로 로드한다.
> 환경 정보·작업 표준을 한 곳에 모아 일관된 지원을 받기 위함.

---

## 사용자 환경

- **OS**: Windows 10/11
- **셸**: PowerShell (Bash 도구도 사용 가능)
- **개발 환경**:
  - 백엔드: Java/Spring (Spring Boot, Spring Security)
  - 프론트엔드: **Thymeleaf 기반 서버사이드 렌더링(SSR)**. React/Vue SPA가 아님
  - DB: IBM DB2 (회사 환경)
- 주제별로 환경이 다를 수 있으니 시작 전 확인할 것

---

## 부트캠프 커리큘럼 작성 가이드

사용자가 "X 주제 부트캠프 커리큘럼 짜줘"라고 요청하면 아래 절차를 그대로 따른다. 이 패턴은 보안 부트캠프 작성에서 사용자가 검증·승인한 템플릿이다.

### 1) 시작 전 반드시 질문 (AskUserQuestion으로 한 번에 4개)

이론 일반론을 피하고 사용자 환경에 맞춤화하기 위해:

1. **현재 수준** — 입문 / 기초 있음 / 중급 (시나리오로 구분)
2. **집중 영역** — 주제의 하위 분야 (멀티 선택 가능)
3. **기술 스택** — 멀티 선택 (위 환경 정보를 참고하되 재확인)
4. **분량·페이스** — 4주 집중(추천) / 8-12주 심화 / 핸드북

답변 받기 전에는 작성 시작 X.

### 2) 표준 디렉토리 구조

```
[topic]_bootcamp/
├── README.md                  ← 전체 안내, 학습 흐름, 윤리/주의사항, 사전 준비물
├── week1_[topic]/
│   ├── 00_overview.md         ← 주차 목표·일정 표
│   ├── 01_*.md ~ 0N_*.md      ← Day별 핵심 콘텐츠 (5일치)
│   ├── labs/                  ← 실습 가이드
│   └── checklist.md           ← 자가 점검
├── week2_*/ ... week4_*/
├── practice_app/              ← 실습 코드 (주제에 따라 명칭 변경)
└── resources/
    ├── tools.md
    ├── books_and_courses.md
    ├── glossary.md
    ├── quick_reference.md     ← 코드 작성 시 펴볼 한 페이지 카드
    └── (주제별 추가)
```

기본 **4주 × 5일 = 20개 Day** + 주차별 체크리스트 + 캡스톤.

### 3) 각 .md 파일 표준 구조

```
# Day N — 주제
## 한 줄 요약
## 학습 목표 (체크박스 5~8개)
## 본론 (개념 → 위험 패턴 → 안전 패턴 → 실제 사례 → 도구)
## 코드 예제: // ❌ 위험  vs  // ✅ 안전 페어
## 실습 (Hands-on, 1~4단계)
## 더 읽어볼 자료 (📘책 / 🔗링크 / 🎓강의)
```

### 4) 사용자 스택 특화

일반론보다 **사용자 코드베이스에 즉시 적용 가능한 예제**. Java/Spring + Thymeleaf SSR 맥락이 기본값. 단, 주제별로 다를 수 있으니 시작 전 재확인.

### 5) 실습 앱 패턴

학습 주제별 미니 앱을 함께 작성. 가능하면 **안티 패턴(`/vuln/*` 등) vs 권장 패턴(`/safe/*` 등) 쌍**으로 같은 기능을 비교 가능하게 구성.

### 6) 문체·포맷 표준

- **한국어 + 기술 용어 영어 병기**: "위협 모델링(Threat Modeling)"
- **표 적극 사용**: 비교·매핑·체크리스트
- **이모지는 ✅ ❌ ⚠ 📘 🔗 🎓 정도만 강조용**
- **권장 vs 비권장 시각화** (코드 주석 ❌/✅, 표의 ✓/X 컬럼)
- **출처·표준 인용**: OWASP, NIST, RFC, 벤더 공식 문서
- **분량을 아끼지 않는다** — 사용자가 깊이·예제·체크리스트가 풍부한 것을 선호
- **실제 사례·CVE를 매 주제에 포함**

### 7) 마지막 주차에 캡스톤

종합 적용 프로젝트. 보고서 템플릿·채점 가이드·다음 단계(자격증·심화) 추천 포함.

### 8) Resources 5종 세트 항상 포함

- `tools.md`, `books_and_courses.md`, `glossary.md`, `quick_reference.md` + 주제별 추가

### 9) 작업 절차

1. AskUserQuestion으로 4가지 확인
2. TodoWrite로 작업 계획 (대략 7~8개 항목)
3. 디렉토리 생성
4. README → Week별 → 실습앱 → 리소스 순서
5. 각 주차 완료 시 TodoWrite 업데이트
6. 마지막에 시작 지점(`week1/00_overview.md`) 안내

### 10) 주의 사항

- 메모리/이 파일에 저장된 사용자 환경을 활용하되 **변경 가능성을 인지하고 재확인** (예: 보안 부트캠프 작성 중 사용자가 "React가 아니라 Thymeleaf"라고 정정한 사례)
- 윤리/법률 가드레일이 필요한 주제(보안, AI 데이터 수집 등)는 README에 명시
- 도구·라이브러리는 최신 메이저 버전 (Spring Boot 3.x, JDK 17+ 등)
- 실습 코드는 **Windows + PowerShell 환경**에서도 동작하는지 고려
