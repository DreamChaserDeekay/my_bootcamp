## 13. 자주 묻는 질문

### "Spring Boot vs Spring 어느 것?"
Boot로 시작. Boot 안에 Spring이 있음. Boot의 마법을 풀어나가며 배우면 자연스럽게 Spring 이해.

### "Reactive(WebFlux) 배워야 하나?"
JDK 21 Virtual Thread 등장 후 정당화 어려워짐. 일반 backend면 Tomcat + VT가 더 단순·빠를 수 있음. **꼭 필요한 환경**(SSE/WebSocket 대규모)에서만 학습.

### "Kotlin Spring?"
선택. Java 21이 record·pattern matching 등 따라잡았음. 팀 결정 사항. 개인적으로 학습 효율은 Java 중심.
