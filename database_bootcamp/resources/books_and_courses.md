# 도서·강의

## 1. 입문

### 📘 『SQL First Aid』 (Bill Karwin)
- 짧고 실용적 — 막혔을 때 빠른 답

### 📘 『Learning SQL』 (Alan Beaulieu, O'Reilly)
- SQL 입문서 표준
- 부트캠프 Week 1 보충

### 📘 『이것이 MySQL이다』 (우재남)
- 한국어 MySQL 입문서

## 2. 중급 (SQL 심화)

### 📘 『SQL Antipatterns』 (Bill Karwin)
- 25개 안티패턴 + 해결책
- 부트캠프 Week 1 Day 5 확장판

### 📘 『SQL Cookbook』 (Anthony Molinaro, O'Reilly)
- 패턴 모음 — 윈도우 함수 활용 예제 풍부

### 🔗 『Use The Index, Luke』 (Markus Winand, 무료)
- <https://use-the-index-luke.com/>
- **인덱스 학습의 정수**. 부트캠프 Week 2 메인 보충자료

## 3. 성능 / 운영

### 📘 『High Performance MySQL』 4th edition (Schwartz et al., O'Reilly)
- MySQL 운영의 바이블
- 부트캠프 Week 2~4 전반

### 📘 『MySQL 8 Cookbook』 (Karthik Appigatla)
- 8.0 신기능 중심

### 📘 『Database Internals』 (Alex Petrov, O'Reilly)
- 스토리지 엔진·B-tree·분산 합의 내부
- 부트캠프 Week 2 보충 (깊이)

### 📘 『Designing Data-Intensive Applications』 (Martin Kleppmann)
- 분산 시스템 + 트랜잭션 + 복제
- 부트캠프 Week 3, 4 보충

### 📘 『Database Reliability Engineering』 (Laine Campbell, Charity Majors)
- DBRE / DB 운영의 SRE 시각

## 4. DB2

### 📘 『DB2 9 Fundamentals Certification Study Guide』 (Roger Sanders)
- DB2 입문·자격증 대비

### 📘 『DB2 Pure Performance for Linux/UNIX』 (Sanyal et al.)
- DB2 튜닝의 정수

### 🔗 IBM DB2 11.5 Knowledge Center
- <https://www.ibm.com/docs/en/db2/11.5>
- 공식 문서 — 가장 권위 있음

## 5. MySQL

### 🔗 MySQL 8.4 Reference Manual
- <https://dev.mysql.com/doc/refman/8.4/en/>
- 공식 문서

### 📘 『MySQL Concurrency』 (Jesper Wisborg Krogh, Apress)
- 잠금·트랜잭션 심화

### 📘 『Pro MySQL NDB Cluster』
- 클러스터 학습

## 6. JPA / MyBatis / Spring Data

### 📘 『자바 ORM 표준 JPA 프로그래밍』 (김영한)
- 한국어 JPA 정석. 강력 추천

### 📘 『High-Performance Java Persistence』 (Vlad Mihalcea)
- JPA 성능의 최고봉. 부트캠프 Week 3 Day 5 심화

### 📘 『MyBatis 3 User Guide』 (무료)
- <https://mybatis.org/mybatis-3/>

### 📘 『Pro Spring 6』 (Iuliana Cosmina)
- 트랜잭션 챕터 등
