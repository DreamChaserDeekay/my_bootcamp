## 입문 → 기초 다지기

### 📘 The Linux Command Line (William Shotts)

- 무료 PDF: <https://linuxcommand.org/tlcl.php>
- bash 기초부터 스크립팅까지 가장 친절한 입문서
- 부트캠프 Week 1, 2의 기반

### 📘 Operating Systems: Three Easy Pieces (Remzi Arpaci-Dusseau)

- 무료: <https://pages.cs.wisc.edu/~remzi/OSTEP/>
- 프로세스·메모리·동시성·파일시스템·분산. OS 수업의 정수
- 부트캠프 Week 1, 4의 OS 이론 부분

### 🎓 MIT 6.NULL: The Missing Semester

- <https://missing.csail.mit.edu/>
- 셸·git·디버깅·메타프로그래밍 등 "대학에서 안 가르치는데 필수인" 것들
- 부트캠프 전반에 도움

## 셸·자동화

- sed·awk·정규식 마스터
- 부트캠프 Week 2 Day 2~3

### 📘 Learn PowerShell in a Month of Lunches (Don Jones, Jeff Hicks)

- PowerShell 입문 최고. 매 챕터가 30분 분량
- 부트캠프 Week 1, 2의 PowerShell 부분

### 📘 PowerShell in Action (Bruce Payette)

- PowerShell의 바이블. 깊이 있음
- 고급 함수·메타프로그래밍

### 📘 PowerShell 101 (Mike F. Robbins, 무료)

- <https://leanpub.com/powershell101>
- 짧고 실용적

## 네트워크

### 📘 TCP/IP Illustrated, Volume 1 (W. Richard Stevens)

- 1994년 책이지만 **여전히 표준**. 패킷 캡처 분석의 정수
- 부트캠프 Week 3 전체

### 📘 Computer Networks (Andrew Tanenbaum)

- 네트워크 교과서 표준
- 더 학문적, OSI 7계층 깊이

### 📘 High Performance Browser Networking (Ilya Grigorik)

- 무료: <https://hpbn.co>
- HTTP/2, HTTP/3, WebSocket, WebRTC. 운영자 관점에서 최고
- 부트캠프 Week 3 Day 4

### 📘 Bulletproof SSL and TLS (Ivan Ristić)

- TLS의 모든 것
- 부트캠프 Week 3 Day 4

### 📘 Practical Packet Analysis (Chris Sanders)

- Wireshark 입문 명서
- 부트캠프 Week 3 Day 5

### 🎓 Stanford CS144: Introduction to Computer Networking

- <https://cs144.github.io/>
- C++로 TCP/IP 스택을 직접 구현하는 과제. 깊이 있는 학습

### 📘 UNIX Network Programming, Vol. 1 (W. Richard Stevens)

- 부트캠프 Week 4 Day 1~2

### 📘 Java NIO (Ron Hitchens)

- Java NIO의 고전. 옛 책이지만 모델은 같음
- 부트캠프 Week 4 Day 2

### 📘 Netty in Action (Norman Maurer)

- Netty 마스터
- 부트캠프 Week 4 Day 3
